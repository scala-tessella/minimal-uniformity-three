# k = 2 scan — producing-run record

Record of the exhaustive rung-2 campaign (2026-07-12, ~2 h): the complete ≤ 24-chamber relaxed
catalogue (`catalogue-size.txt`: 1,363 symbols) scanned over every (symbol, species, designation)
triple. `survivors.tsv` holds the ONE pair passing the combinatorial check and the pinned linear
layer — the (3.4².6) symbol with an irregular-designated hexagon refuted by forced regularity in
`UClassK2VerdictSpec` — so the paper's claim "no U(z) tiling has uniformity ≤ 2" rests on this
single, archived, independently re-refutable survivor. `run.log` is the campaign's heartbeat.

This directory is a *record*, separate from `certs/uclass-k2/`, where a fresh
`sbt -Duclass.k2 test` run writes its own outputs.
